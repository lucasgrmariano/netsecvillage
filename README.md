# NetSec Village

Site estático de uma página para divulgação da comunidade NetSec Village. Não exige instalação nem build.

## Rodar localmente

Abra `index.html` no navegador. Para testar em um servidor local, execute `python -m http.server 8000` nesta pasta e acesse `http://localhost:8000`.

## Publicar no GitHub Pages

Crie um repositório no GitHub e envie os arquivos desta pasta para a raiz da branch `main`. Em **Settings → Pages**, selecione **Deploy from a branch**, branch `main` e pasta `/ (root)`. Depois de salvar, o endereço será exibido nessa mesma tela.

Os botões de comunidade já apontam para o Instagram e o Discord oficiais. A imagem `logo-temp.jpg` é temporária e pode ser substituída por uma versão final mantendo o mesmo nome.
